# 专利附图-GPT · R21 受控试用版

面向 Dify 的专利附图辅助插件和 Chatflow。R21 的交付范围为工程参考。插件版本为 `0.3.9`，实例身份以签名包内容对应的插件 UID 为准。本仓库提供已清除本机绝对路径的可移植构建。

## 安装

1. 用 `shasum -a 256 -c SHA256SUMS` 核对安装包、验签公钥和 Chatflow。
2. 在 Dify 安装 [R21 签名插件](dist/r21.signed.difypkg)。由管理员按实例的插件签名策略核对 [验签公钥](dist/signing-public-key.pem)。
3. 导入 [R21 Chatflow](chatflows/patent-drawing-r21.yml)，将五个工具节点绑定到该插件和目标工作区的工具凭据。凭据在目标实例内配置。
4. 在验证草稿中上传技术交底，通过「预览」确认来源。操作员登记了来源和复审记录均匹配的受限引导后，可使用「导出工程示意」。需要仅导出已保存实际图件时，使用「导出已完成」。

模型执行由目标实例的私有策略控制。试用验证采用关闭模型执行的隔离工作区。配置约定见 [插件说明](plugin/README.md)，其中标记为旧版的章节保留历史版本信息。

## 验证与使用范围

2026-11-10 的 Dify 隔离实例验证使用本地封存的 R21 安装包，核对了 84 个运行文件并执行 5 项原生检查。3 项成功，2 项按预期拒绝，图像、文本和视觉模型调用均为 0。可移植构建只替换规则目录中的案例来源路径字段，并将 DSL 绑定到重建后的插件 UID。本仓库的签名包已通过验签和离线检查，原生验证记录归属于本地封存包。

工程示意导出可将已保存原图与经复审的关系示意一并返回。完整版本和实际空间图的验收状态由工作区独立记录。

正式定稿仍要求实际空间图、整套关联修改、最终同版三案验证以及专业和用户验收。工程示意产物的清单保留 `filing_ready=false`。原始交底、个案图件与原始测试记录单独归档。

## 源码与构建

- [插件源码](plugin/) 的 84 个运行文件来自同一签名包，并逐项校验。
- [Chatflow 构建器](chatflows/build_quality_chatflow.py) 生成可导入的 DSL，可用 `--uid` 绑定指定插件内容身份。
- 在 `plugin/` 中使用 Python 3.12。安装 `requirements.txt` 和 pytest 后，可运行 `python -m pytest -q tests` 执行随包的离线检查。
- 使用 Dify 官方 CLI 构建插件，命令为 `python tools/package_plugin.py --cli <Dify CLI 路径> --output <安装包路径>`。
